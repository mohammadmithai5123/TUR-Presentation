# Taheri Unity Ride

Static presentation for the Taheri Unity Ride. Open `index.html` in a modern
browser; no build step or package installation is required.

## Live site

https://mohammadmithai5123.github.io/TUR-Presentation/

## Project structure

```text
index.html
README.md
assets/
  css/
    styles.css
  fonts/
    body-bold.ttf
    body-regular.ttf
    heading-bold.ttf
  images/
    branding/      Event and organization logos
    landmarks/     Checkpoint and location photography
    maps/          Route-map background
    route/         Route illustrations
    slides/        Cover and feature photography
    stops/         Numbered stop photography
  js/
    presentation.js  Slide navigation, notes, and image magnifier
    route-map.js     Animated route and map controls
```

## Editing

- Update slide content in `index.html`.
- Update presentation styling in `assets/css/styles.css`.
- Keep route animation in `assets/js/route-map.js` and slide behavior in
  `assets/js/presentation.js`.
- Place new images in the matching `assets/images/` category and update their
  paths in `index.html`.
