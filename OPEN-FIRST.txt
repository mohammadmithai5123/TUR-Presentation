TAHERI UNITY RIDE — MERGED PRESENTATION

1. Extract this entire ZIP into a folder.
2. Open index.html in Chrome or Edge. Keep the assets folder beside it.
   The first slide is an interactive title screen: move the mouse and the cyclist follows it. Click START PRESENTATION
   (or press Enter) to begin; Back or Home returns to it. With "reduce motion" on, the cyclist stays still.
3. Right Arrow / Next moves to the next slide; all points on a slide appear together. Back reverses.
4. Move the mouse to show the bottom toolbar (it hides itself); use the slide dropdown to jump.
   F opens fullscreen; M toggles the lens; N shows or hides the speaker notes.
5. The route journeys show every spot at once as a flow chart; click a photo to see it whole.

45 slides in six sections, in this order:
  Route Overview (1-26), Activities (27-35), Taheri Web Application (36-38),
  Communication Application (39-40), Giveaways (41-42), Valuable Sponsors (43-44), then the closing slide (45).
Each of the last five sections opens with its own introduction slide.
The "ONE RIDE. ONE TEAM. ONE COMMUNITY." team-celebration slide is the final slide of the whole deck.

Edits can publish themselves: in Edit Mode, open the GitHub panel once, paste a token (Contents:
Read and write, this repository only), and every later edit is committed and goes live by itself.
See README.md, "Edits go live automatically".

Everything is editable: click Edit Mode in the bottom toolbar, pick a slide, click
text or a picture, and change it. Edits save in the browser automatically;
"Download editable HTML" makes a portable copy (about 40 MB) with the editor inside.

Editable source: src/slides/*.html and src/slides.json.
Rebuild after edits: npm run build (Node.js only; no packages required).
The built index.html works without Node.js or internet.
