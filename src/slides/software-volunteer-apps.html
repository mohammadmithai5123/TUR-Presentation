TAHERI UNITY RIDE / WEB APPLICATION

Volunteer Applications

Checkpoint Volunteer Application

Displays the volunteer’s assigned checkpoint.

Scan the cyclist’s QR card or manually enter the participant ID.

Tracks the number of arrivals and displays recent check-ins.

Activity Volunteer Application

Displays the volunteer’s assigned activity.

Scan the participant’s QR card or enter their ID at both the start and finish

Tracks activity starts and completions, including start time, finish time and result.

Scanning Process

Checkpoint volunteers scan each cyclist’s QR card upon arrival. Activity volunteers scan the same card twice: once when the activity begins and again when it is completed.

Scan Records & Reporting

Every scan is linked to the participant’s unique ID and displayed in the volunteer’s report. All records are synced with the central dashboard to update checkpoint progress, the live leaderboard and activity rankings.
