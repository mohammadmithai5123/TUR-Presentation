TAHERI UNITY RIDE / WEB APPLICATION

Volunteer Applications

Checkpoint Volunteer Application

Displays the volunteer’s assigned checkpoint.

Scan the cyclist’s QR card or manually enter the participant ID.

Tracks the number of arrivals and displays recent check-ins.

Activity Volunteer Application

Displays the volunteer’s assigned activity.

Scan the participant’s QR card or enter their ID at both the start and finish

Counts started and completed; recent entries show start, end and result.

How they scan

Checkpoint volunteers scan each cyclist’s QR card as they arrive. Activity volunteers scan the same card when the activity starts and again when it finishes.

What is displayed

Every scan is saved against the participant and shows in the volunteer’s own report. All scans feed the dashboard: checkpoint progress, the live leaderboard and the activity rankings.
